Proyecto Java que implementa comunicación cliente-servidor usando protocolos TCP y UDP.

## 📝 Descripción
Sistema de comunicación que incluye:
- Servidor TCP concurrente
- Cliente TCP básico
- Servidor UDP simple
- Cliente UDP básico
- Ejemplos de comunicación bidireccional
